# 🔬 Research Spotlight

## ⚡ FCDC — Nonvolatile Charge-Domain Attention

### *Nonvolatile Charge-Domain Attention with HZO Ferroelectric Capacitors*

**A Simulation-Based Device-to-System Evaluation**

<p>
  <a href="https://arxiv.org/abs/2605.28208">
    <img src="https://img.shields.io/badge/arXiv-2605.28208-B31B1B?style=for-the-badge&logo=arxiv&logoColor=white" />
  </a>
  <a href="https://github.com/faris-agour/FCDC">
    <img src="https://img.shields.io/badge/Code-FCDC-181717?style=for-the-badge&logo=github&logoColor=white" />
  </a>
</p>

**Sole-author research** exploring a nonvolatile charge-domain architecture for efficient transformer attention and persistent KV-cache storage.

The work studies the problem across the full stack:

```text
HZO Device
    ↓
Circuit
    ↓
Compute-in-Memory Array
    ↓
Transformer Attention
    ↓
LLM Evaluation
    ↓
Serving-System Energy
```

### Main Ideas

- Persistent **nonvolatile KV-cache residency**
- **HZO ferroelectric capacitors**
- Charge-domain **vector-matrix multiplication**
- Compute-in-memory for transformer attention
- Long-context and long-lived LLM workloads
- Memory movement and energy efficiency
- Hardware-aware model evaluation
- Device-to-system co-design

> The broader question behind the work:
>
> **Can we change where AI state is stored and computed to reduce the cost of moving and maintaining that state?**
